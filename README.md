## ✨ Features

- Responsive hero section with profile photo and quick links (Projects, Contact, Resume)

- Tech stack grid with categorized skill icons
- Working contact form (email delivery via FormSubmit) with direct links to LinkedIn, GitHub, and LeetCode

## 🏁 Getting Started

Clone the repo and run it locally:

```bash
git clone https://github.com/Shital-3/shital-portfolio.git
cd shital-portfolio
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

Build for production:

```bash
npm run build
```
